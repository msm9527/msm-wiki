# 配置管理

MSM 有两类配置入口：

- **服务专属编辑器**：DNS服务或代理服务中的结构化 / 原始配置
- **全局配置管理**：从文件树浏览、编辑、上传和下载 MSM 配置目录

日常修改优先使用服务专属编辑器，因为它能按当前核心校验结构并协调服务生效。全局配置管理适合处理尚未被结构化页面覆盖的文件。

## 全局配置管理能力

- 文件树和多标签编辑
- 新建、复制、重命名与删除文件 / 目录
- 上传和下载
- 按服务类型校验
- 配置历史、差异、稳定标记与回滚

读取完整文件树通常需要基础 Pro；写入、上传和删除需要 `config.write`；增强历史操作需要 `config_history_enhanced`。高风险写操作还可能要求在线授权。

## 代理配置

- Mihomo 使用 YAML
- Sing-Box 使用 JSON
- 当前活动核心从 **代理服务 → 配置编辑** 进入
- 结构化编辑会尽量保留未修改的原生字段
- YAML 写入会尽量保留注释和顺序，但自动迁移仍可能重排相关块

不要同时在全局文件树和代理专属编辑器打开同一文件修改，以免保存顺序覆盖另一份变更。

## 推荐流程

1. 创建备份或确认已有可回滚历史
2. 选择服务专属页面或全局文件树
3. 修改后先执行校验
4. 查看保存差异
5. 按提示应用或重启服务
6. 检查运行状态和最近日志

## 安全边界

- 不支持把二进制文件当文本编辑
- 不在配置中明文粘贴不必要的 Token 和私钥
- 上传文件前确认目标路径和当前服务
- 删除 / 重命名前检查引用关系
- 核心切换使用 [统一代理服务](/zh/guide/proxy)，不要只替换二进制或配置文件
