# 域名服务

**域名服务**把动态域名解析、HTTPS 证书和反向代理串成一条可观测、可恢复的发布链路，适合把 NAS、相册、家庭面板等 Web 服务通过自己的域名安全发布。

该模块属于 Pro 功能，并受 **系统设置 → 功能开关 → 域名服务** 控制。

## 发布链路

```text
内网 Web 服务
  ↓ 健康与可达性检查
DDNS：域名指向家庭公网地址
  ↓ 权威解析验证
ACME：申请或导入 HTTPS 证书
  ↓ 证书加载
反向代理：域名 → 内网目标
  ↓
公网 HTTPS 验证与持续健康检查
```

## 快速发布一个域名

进入 **域名服务 → 概览**，点击 **发布一个域名**。向导会按阶段执行：

1. 填写服务名称、域名和内网目标 URL
2. 新建或选择 DNS 服务商凭据
3. 创建并同步 DDNS 记录
4. 申请新证书或选择已有证书
5. 创建反向代理路由并校验配置
6. 从公网域名执行最终 HTTPS 检查

每个阶段都会先执行预检。失败后可修正当前阶段并继续，不必从头重复创建已成功的资源；需要放弃时可清理当前工作流并重新开始。

## 动态域名解析

进入 **域名服务 → 动态域名解析** 管理 DNS 凭据和任务。

### 建议流程

1. 使用服务商提供的最小权限 Token / API 凭据
2. 测试凭据可用性
3. 填写域名、记录类型、TTL 和检查间隔
4. 选择公网 IPv4 / IPv6 来源
5. 保存并执行 **立即同步**
6. 等待权威 DNS 验证与服务商记录一致

任务会分别记录服务商写入状态和权威解析验证状态。出现“已写入但尚未传播”时，先等待 TTL 和 DNS 传播，不要反复删除重建。

::: tip 与自建私网联动
WireGuard 自建私网可以直接选择已就绪的 DDNS 任务作为 Endpoint。先让 DDNS 任务通过权威解析验证，再进入 [自建私网](/zh/guide/networking)。
:::

## HTTPS 证书

进入 **域名服务 → 证书管理**。

### ACME 自动签发

简单模式默认使用 DNS-01，支持通配符，并且不要求公网开放 80 / 443 端口。可选择 Let's Encrypt、ZeroSSL 或受信任的自定义 ACME Directory。

建议先使用 Staging 完成流程验证，再明确确认切换到 Production。Staging 证书不受浏览器信任，不能用于生产 HTTPS 路由。

专家模式还可选择 HTTP-01 或 TLS-ALPN-01：

- HTTP-01 需要公网 80 端口到达当前代理服务，不支持通配符
- TLS-ALPN-01 需要公网 443 端口到达当前代理服务，不支持通配符
- 创建订单前先运行申请前检查

### 导入已有证书

可以粘贴 PEM，或从 MSM 配置目录下受限的 `imports` 路径导入。保存前会校验证书链、有效期、域名和私钥是否匹配。

私钥属于高度敏感数据。MSM 会加密存储，但你仍不应在日志、截图、工单或聊天中传播私钥。

### 生命周期

- 自动续期会在续期窗口内启动
- 失败按退避策略重试，并显示下次尝试时间
- 尚未过期的旧证书会继续使用
- 已被反向代理引用的证书不能直接删除
- 生产签发受 CA 速率限制，不要反复创建相同订单

## 反向代理

进入 **域名服务 → 反向代理**，填写域名与内网目标 URL。保存后 MSM 会：

1. 验证域名、目标和证书关系
2. 生成代理运行时配置
3. 安全加载新配置
4. 检查目标健康状态
5. 在失败时保留或恢复上一份可用配置

常用能力包括 HTTPS 终止、WebSocket、路径前缀、健康检查、访问日志，以及高级的多上游、超时、重试和请求 / 响应头设置。

### 目标地址建议

- MSM 与目标同机：使用目标真实监听地址和端口
- MSM 在 Docker 内：不要想当然地使用 `127.0.0.1`，应使用容器可访问的宿主机或服务地址
- 目标使用自签名 HTTPS：谨慎配置上游 CA 和 SNI，不要直接关闭所有验证

## 状态与诊断

概览会分别显示 DDNS、有效证书、健康路由和 DNS 服务商数量。事件时间线记录各阶段的执行结果，同时隐藏凭据和私钥。

出现问题时按链路顺序排查：

1. **DDNS 诊断**：服务商记录、权威解析、当前公网地址
2. **证书状态**：签发环境、挑战方式、有效期、运行时加载
3. **反向代理健康**：目标连通性、HTTP 状态和延迟
4. **发布链路诊断**：DNS → TLS → 路由的整体结果
5. **访问日志**：客户端请求是否到达、返回状态码

## 安全建议

- DNS 凭据只授予所需区域和记录的最小权限
- 生产前先用 Staging 验证 ACME 流程
- 不要把家庭管理面板裸露到公网；配合强认证、访问策略或 VPN
- 定期检查证书到期、代理健康和事件时间线
- 删除资源前确认依赖关系，先解除路由与证书绑定
