# 隐私与数据安全

> 版本：`1.0` · 更新日期：2026 年 8 月 18 日

本页将 **MSM Wiki 文档站** 与 **用户自行部署的 MSM 软件** 分开说明。两者的托管者、数据流向和用户控制范围不同，不应混为一谈。

## 文档站的数据边界

MSM Wiki 是静态文档站，官方域名为 `doc.msmbox.net`。截至本页更新日期：

- 文档站未主动嵌入广告、用户画像或第三方行为分析脚本
- 站内搜索在浏览器中使用随站点构建的索引
- 深色/浅色主题等界面偏好可由浏览器本地存储记住
- 文档站由 GitHub Pages 托管，并可能经过 DNS/CDN 服务商传输；这些服务商可能按各自政策处理 IP 地址、时间、User-Agent、请求路径和安全日志
- 点击 GitHub、Telegram、博客或其他外部链接后，对方站点的隐私政策和服务条款独立适用

文档站不用于提交密码、Token、私钥、订阅地址、许可证文件、未脱敏备份或生产日志。

## 自托管 MSM 的数据边界

MSM 通常由用户在自己的主机、虚拟机或容器中运行。账号、配置、日志、密钥和运行数据默认存在该部署环境及其备份中，不因使用本文档站而自动上传。

但“自托管”不等于“永不发生外部请求”。当用户启用对应功能时，MSM 或其受管组件可能连接：

| 功能 | 可能连接的对象 | 用户应核对的内容 |
| --- | --- | --- |
| 版本与组件更新 | GitHub、国内镜像、组件上游 | 下载来源、校验值、代理与镜像信任 |
| 订阅、规则与数据源 | 用户填写或选择的提供者 | URL 的合法来源、鉴权信息、提供者政策 |
| DDNS、ACME 与域名发布 | DNS 服务商、ACME 机构、反向代理目标 | 域名权属、API 凭据、证书私钥、服务条款 |
| Cloudflare、私网与远程接入 | 用户选择的控制面、中继或对端 | 账号、组网成员、路由范围、日志与跨境传输 |
| 公网 IP 与网络诊断 | 外部 IP 检测站点、DNS/HTTP/SSL/测速目标 | 目标授权、外部可见元数据、测试流量 |
| 许可证与在线能力 | 许可或授权服务 | 当前版本实际发送字段、服务协议、失效和恢复机制 |

实际请求字段和保留时间取决于软件版本、功能配置与第三方服务。上表用于帮助进行数据流审计，不代替对实际网络请求、日志和服务条款的检查。

## 可能存储的敏感资产

MSM 的功能范围决定了本地部署中可能存在：

- 管理员、操作员、查看者账号及会话信息
- API Token、许可证凭据、第三方服务 Token 和订阅 URL
- DNS 查询、代理连接、访问日志和设备标识信息
- 域名解析凭据、ACME 账号、证书与私钥
- Docker Agent、私网、远程访问和控制面密钥
- 包含上述内容的配置历史、诊断包、数据库与备份

不要仅保护当前配置。历史版本、旧容器卷、快照、诊断导出和离线备份也可能保留已更换的凭据。

## 部署者的安全与隐私责任

### 最小化

- 只收集和保留完成明确目的所必需的日志与数据
- 按组织需求配置保留期，定期删除过期诊断包、日志和备份
- 共享排障信息前脱敏 IP、域名、账号、订阅、Token、私钥和业务数据

### 访问控制

- 使用独立强密码、最小权限角色和必要的 API Token 有效期
- 管理界面不应无认证直接暴露在公网
- 优先使用 HTTPS、私网、VPN 或其他经过身份验证的管理通道
- 定期审计管理员、API Token、Agent、Peer、域名凭据和许可证状态

### 数据保护

- 保护 MSM 数据目录、数据库、容器卷、配置历史与备份的文件权限
- 对备份进行加密、离线或异地保护，并定期测试恢复
- 当成员离开、凭据暴露或授权范围改变时，立即撤销和轮换相关凭据
- 安装更新前核对官方来源和校验信息，并保留回滚能力

## 个人信息与组织数据

如果 MSM 的 DNS、连接、访问、设备或账号数据可以识别特定自然人，部署者应根据适用法律确定自己的角色和义务，并至少考虑：

- 是否具有明确、合理的处理目的与合法基础
- 是否已向相关人员说明数据类型、用途、保留期和共享范围
- 是否存在第三方委托处理、对外提供或跨境传输
- 是否需要影响评估、事件通知、查阅更正删除通道或其他合规措施

## 安全问题与日志提交

如果需要在 GitHub Issue 或社区中排查问题：

1. 先复制日志到本地临时文件。
2. 删除密码、Token、Cookie、证书私钥、订阅 URL 和许可证内容。
3. 将公网 IP、内网网段、域名、邮箱、设备名和用户名替换为示例值。
4. 仅提交复现问题必需的最小片段。
5. 如果已经公开凭据，不要只删帖，应立即在对应服务中撤销和轮换。

## 文档性质

本页是技术与风险边界说明，不是对任何特定地区、行业或部署的法律意见。用户应根据实际的数据流、合同关系、组织规模和适用法律建立自己的隐私声明与安全制度。
