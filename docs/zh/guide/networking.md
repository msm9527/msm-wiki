# 自建私网

**自建私网（`/networking`）**用于将外出设备、异地住宅或云服务器加入家庭虚拟专网。MSM 可以同时独立管理 **WireGuard**、**EasyTier** 和 **Tailscale**；每个引擎拥有独立的安装生命周期、配置、运行态指标、成员设备列表、日志与诊断，不再是三选一向导。

::: warning 仅连接已授权成员
私网可让远端设备获得家庭内网路由。只向可信成员发放凭据，只发布必要网段；成员离开或凭据暴露后应立即撤销并轮换密钥。
:::

该模块属于 Pro 扩展能力，受 **应用商店安装状态**、**系统设置 → 功能开关 → 自建私网** 以及用户角色控制（管理员和操作员可配置，查看者只读）。在 **应用商店（`/apps?category=networking`）** 可按需单独安装或安全卸载任意一个引擎——卸载时 MSM 会自动停用运行态接口与守护进程、清理托管二进制与配置，同时不影响宿主系统包和已保存的对端设备记录。

## 三种引擎可以并存

| 引擎 | 适合场景 | 主要特点 |
|------|----------|----------|
| **WireGuard** | 追求极致性能、低开销与完全可控 | 支持 Linux 原生内核接口与用户态回退、DDNS Endpoint 联动、一次性客户端私钥，并可融入移动端单 TUN 回家包 |
| **EasyTier** | 无公网 IP 的快速点对点 / 中继组网 | 配置直观，支持公共或自建 Peer、DHCP 或固定虚拟 IP、托管字段与高级 TOML 参数编辑 |
| **Tailscale** | 已使用 Tailscale 或自建 Headscale 控制面 | Auth Key 注册设备，支持接收远端路由、发布家庭 LAN 路由或出口节点（Exit Node） |

三个引擎可以同时配置与启动，但必须避免虚拟网段、接口名、监听端口与发布路由重叠。并存时应为不同设备或冗余路径规划清晰网段，不要把同一网段无差别地重复发布给全部引擎。

## 工作台结构与配置流程

进入 **回家与私网 → 自建私网（`/networking`）**，页面包含四个核心区域：

- **顶栏与隐私保护**：展示运行服务数或待登录提示，提供 **一键隐私模式**（自动脱敏公网 Endpoint 与 IP）、应用商店快捷入口以及直达 [终端配发（`/networking/delivery`）](/zh/guide/home#终端配发工作台-networking-delivery) 的按钮
- **核心摘要与拓扑横幅**：实时汇总已配置引擎、运行中数量、已登记设备与在线设备数，并以拓扑条展示各引擎虚拟网段与共享家庭局域网路由
- **引擎服务卡片**：每个已安装引擎独立一张卡片，展示运行状态、实时指标、接口与端口信息，并提供独立的启动/停止/重启、配置、日志与诊断操作
- **统一成员列表**：每 10 秒自动刷新各引擎在线成员与最近握手状态，支持按引擎添加、编辑或撤销设备

### 标准配置步骤

1. 在 **应用商店** 安装需要的组网引擎（WireGuard / EasyTier / Tailscale）
2. 在目标服务卡片点击 **配置**，设置节点身份、虚拟网段、连接方式与共享的家庭 LAN 路由
3. 保存配置并启动服务，点击 **诊断** 核对接口、路由与连通性
4. 点击 **添加设备**（或跳转 **终端配发**）为外出设备签发接入配置

启用自动启动后，MSM 会在自身重启或主机重启后自动恢复该服务；手动停止会被记住，不会被后台健康检查误拉起。

## WireGuard

WireGuard 需要一个远端可达的 Endpoint。配置弹窗支持三种 Endpoint 来源：

- 直连检测到的公网 IPv4 / IPv6
- 直接选择 [域名服务](/zh/guide/domain-services#动态域名解析-ddns) 中已通过权威解析验证的 DDNS 域名
- 手动填写自定义域名或 IP 地址

同时配置监听端口、虚拟网段、本机地址与需要发布的家庭 LAN CIDR。使用公网 Endpoint 时，卡片会自动提示路由器与防火墙的 UDP 端口映射要求。

### 原生内核模式与跨平台兼容

- **Linux 原生内核支持**：当宿主内核支持 WireGuard 且具备相应权限时，MSM 会优先使用原生内核接口以获得更高吞吐与更低 CPU 占用，并针对 OpenWrt `fw4` / `nftables` 环境自动维护转发与伪装规则
- **修复与自检**：如遇接口异常或防火墙转发缺失，可通过弹窗内的诊断与修复工具快速定位
- **移动端单 TUN 融合**：配置好 WireGuard 后，可在 [终端配发（`/networking/delivery`）](/zh/guide/home#mobile-bundle) 中自动将其以 `WG-HOME` 通道内嵌到 Clash / Sing-Box / Loon 手机配置中，无需同时开启两个 VPN 应用

::: warning DDNS 必须先就绪
配置界面会展示 DDNS 域名的权威解析状态。请勿选择仍在等待传播或同步失败的域名作为生产 Endpoint。
:::

## EasyTier

EasyTier 适合无公网 IP 或复杂 NAT 环境下的异地组网：

- 支持一键启用公共中继节点快速联调，也可填写一个或多个域名/IP 形式的自建初始 Peer
- 当初始 Peer 使用域名时，MSM 会将其同步至 MosDNS 直连名单，避免透明代理 DNS 误改写连接目标
- 支持在图形表单中配置共享家庭 LAN 路由与常用启动项，并在高级区直接预览和校验生成的 `easytier.toml`
- 虚拟地址支持 **DHCP 自动分配** 或 **固定本机地址**，二者互斥

公共节点适合快速验证；长期生产环境建议评估可用性与延迟，并部署自有 EasyTier Peer。共享网络密钥可让设备加入整个虚拟网络，仅限通过可信渠道分发。

### DHCP 与固定本机地址

开启 DHCP 后，MSM 生成的 EasyTier 配置仅写入 `dhcp = true`，**不会生效弹窗中的本机地址**。EasyTier 每次启动会重新挑选空闲虚拟 IP；当对端仍缓存旧路由时，重启或升级后虚拟 IP 可能漂移（例如从 `10.10.0.1` 变为 `10.10.0.4`）。

如果需要通过固定虚拟 IP 访问 MSM 或家庭内网（SSH 跳板、监控、固定路由规则等），请 **关闭 DHCP** 并填写固定本机地址。此时配置写入 `ipv4 = "<本机地址>"` 与 `dhcp = false`，重启后地址保持稳定。组网内每个节点的固定地址必须唯一，建议所有长期在线设备均采用固定地址。

可在 `~/.msm/configs/networking/easytier.toml` 核对最终生效配置，或在 EasyTier 日志中搜索 `dhcp ip changed` 排查历史分配记录。

## Tailscale / Headscale

Tailscale 引擎兼容官方控制面与自建 Headscale：

- 填写控制服务器 HTTPS 地址（留空或默认使用官方控制面）
- 使用控制面签发的 Auth Key 自动注册当前设备（已保存的 Auth Key 不会在接口中明文回传；一次性 Key 注册完成后可在控制面撤销）
- 支持按需开启 **接收远端路由**、**发布当前家庭 LAN 路由** 或 **作为出口节点（Exit Node）**
- 若需要浏览器交互授权，页面顶栏与服务卡片会明确提示待登录状态并提供引导链接

更换登录控制面时，必须使用新控制面重新签发的 Auth Key，并在控制面审批对应的子网路由或出口节点。

## 添加成员与双开防冲突

点击 **添加设备**（或进入 **终端配发 → 电脑 / NAS 原生组网**）选择目标引擎即可生成客户端接入资料：

- **WireGuard**：生成完整客户端配置与二维码；**客户端私钥仅在创建时返回一次**，关闭弹窗前需确认已扫码、复制或下载
- **EasyTier**：生成包含网络名称、初始 Peer 与共享密钥的加入资料与命令行参数
- **Tailscale**：提供同一控制面的加入指引与状态确认

::: tip 电脑同时开代理 TUN 与自建私网？
当电脑同时开启代理软件 TUN 模式与 WireGuard / EasyTier / Tailscale 时，家庭局域网流量容易被代理客户端抢走。可在 [终端配发（`/networking/delivery`）](/zh/guide/home#desktop-mesh) 中一键复制 **防代理 TUN 抢路由直连规则**（支持 Clash / Sing-Box / Surge），并将内网私有域名加入 `fake-ip-filter`。
:::

发布远端 LAN 路由前，请先确认两端局域网网段不冲突（例如两地同为 `192.168.1.0/24` 时路由无法区分目标站点，应先调整其中一侧网段）。

## 与代理协议回家的双向协同

- **网段自动同步**：在自建私网中发布的家庭局域网 CIDR，打开 [代理协议回家（`/networking/inbound`）](/zh/guide/home) 时会自动提示一键合并，避免重复维护两份网段列表
- **多路径容灾**：建议同时保留「代理协议回家」与至少一条「自建私网」通道，在运营商 QoS、端口变更或单引擎维护时仍可通过备用通道访问家中服务

## 运行状态、日志与诊断

每张服务卡片均支持独立启动、停止、重启、查看实时日志和执行结构化诊断。各引擎也会同步出现在统一进程管理与日志窗口列表中。

诊断会自动核对以下链路：

- 托管二进制与配置文件是否完整
- 进程是否运行、虚拟接口与虚拟地址是否就绪
- Endpoint / 控制面 / 初始 Peer 是否网络可达
- 对端成员是否在线、最近握手时间是否正常刷新
- 发布的家庭 LAN 路由与防火墙转发是否生效

“服务运行中”只证明本机进程与接口正常。最终验收务必从真正位于外网的设备验证能否连通 MSM 虚拟地址及至少一台家庭 LAN 设备。

## 并存排错顺序

1. 确认各引擎使用互不重叠的虚拟 CIDR 和接口名称
2. 检查 WireGuard 与 EasyTier 的监听端口没有互相冲突，也没有与 Edge 网关规则冲突
3. 不要让多个引擎同时发布完全相同的默认路由或家庭网段，除非已明确规划路由优先级
4. 查看对应引擎自己的日志；`terminate signal received` 通常为正常停止或重启信号，不代表引擎互斥
5. 若只能访问 MSM 本机、无法访问局域网其他设备，依次检查系统 IP 转发、主路由或家庭设备回程路由、防火墙以及远端设备是否允许接受路由

## 常见问题

### WireGuard 无法握手

检查 Endpoint 域名解析结果、路由器 UDP 端口转发、两端系统时间、密钥配对与 `AllowedIPs`。请关闭 Wi-Fi 使用蜂窝网络测试，避免局域网 NAT 回环干扰判断。

### Tailscale 保存后无法注册

确认控制服务器为有效 HTTPS 地址，且 Auth Key 属于对应控制面并未过期。使用 Headscale 时需同时检查预授权 Key、命名空间/用户及路由审批状态。

### EasyTier 虚拟 IP 重启后变化

检查是否开启了 DHCP。开启 DHCP 时本机地址不生效，虚拟 IP 会动态分配；需要固定地址请关闭 DHCP，详见 [DHCP 与固定本机地址](#dhcp-与固定本机地址)。

### EasyTier Peer 域名无法连接

先使用 [网络工具](/zh/guide/network-tools) 直连解析 Peer 域名，再确认其已加入 MosDNS 直连名单，并核对协议、端口、共享密钥与对端监听状态。
