# 域名服务（Edge 网关）

**域名服务（Edge 网关）**将动态域名解析（DDNS）、HTTPS 证书管理、L7 反向代理、L4 端口转发（含 443 零解密多协议分流）、STUN 内网穿透与全链路实时流量拓扑整合在同一工作台，适合将家庭 NAS、相册、AI 应用、管理面板以及 TCP/UDP 服务安全、可观测地对外发布。

::: warning 域名和服务授权
仅可修改自有或已授权域名的 DNS，为已授权域名申请证书，并转发或代理自有及已授权服务。公网发布前应开启身份验证、HTTPS、最小暴露面和必要的访问审计。
:::

该模块属于 Pro 扩展能力，首次使用需在 **应用商店（`/apps`）** 安装并在 **系统设置 → 功能开关 → 域名服务** 中开启。

MSM 采用**进程内纯 Go Edge 网关引擎**，直接由 MSM 自身承载 HTTP/HTTPS 反向代理、智能微缓存、ACME 证书签发与热加载、L4 TCP/UDP 转发、443 SNI 分流与 STUN NAT1 打洞，**无需额外安装或维护外部反向代理二进制**。

## 工作区总览

| 工作区 | 路由 | 核心能力 |
|--------|------|----------|
| **概览** | `/edge/overview` | 汇总 DDNS、证书、L7/L4/STUN 规则与网关引擎状态，提供一键发布向导 |
| **服务拓扑** | `/edge/topology` | 四列全链路实时流量拓扑图，查看 QPS、带宽、并发连接、健康度与一键隐私打码 |
| **动态域名解析** | `/edge/ddns` | 管理 12 家 DNS 服务商凭据、IPv4/IPv6 双栈 DDNS 任务、权威解析核验与诊断 |
| **证书管理** | `/edge/certificates` | ACME（DNS-01 / HTTP-01 / TLS-ALPN-01）自动签发、续期、PEM 导入与部署钩子 |
| **反向代理** | `/edge/proxies` | L7 域名反代、免域名端口直通、智能全兼容、严格防跨站、41 款应用预设、微缓存与安全访问控制 |
| **端口转发** | `/edge/forwards` | L4 TCP/UDP 高速转发、端口段映射、IPv6→IPv4 桥接、PROXY Protocol 与 443 零解密 SNI 分流 |
| **穿透隧道** | `/edge/tunnels` | STUN NAT1 全锥形直连打洞、UPnP/NAT-PMP 自动映射与免端口 302 域名跳转联动 |

## 发布链路

```text
内网服务（HTTP / HTTPS / TCP / UDP / Docker 容器）
  ↓ 局域网与容器上游自动发现 · 连通性与协议探测
DDNS：域名指向家庭公网 IPv4 / IPv6（权威 DNS 核验）
  ↓ ACME 自动签发 / 复用泛域名证书 / 部署钩子导出
进程内纯 Go Edge 网关引擎（原子校验与零中断热重载）
  ├── L7 反向代理（域名反代 / 端口直通 / 智能全兼容 / 微缓存 / 鉴权）
  ├── L4 端口转发 & 443 零解密多协议分流（TLS SNI / HTTP / SSH / RDP / SOCKS5）
  └── STUN NAT1 穿透隧道（联动 DDNS 与免端口 302 跳转）
  ↓
全链路实时拓扑、6 阶段发布诊断、访问日志与健康检查
```

## 快速发布一个服务

进入 **域名服务 → 概览**，点击 **一键发布向导**。向导分阶段完成校验与落地：

1. 填写服务名称、域名与内网目标 URL（支持一键扫描本机与 Docker 容器端口，并自动识别常见应用推荐预设）
2. 新建或选择 DNS 服务商账号
3. 创建并同步 DDNS 记录，等待权威解析核验
4. 申请新证书、行内自动签发或复用已有通配符证书
5. 创建反向代理规则并通过冲突校验与原子热加载
6. 对公网域名执行最终 HTTPS 可达性检查

每个阶段均包含预检，失败后可直接修正当前阶段继续，无需重复创建已成功资源。若只需将内网服务直接暴露到某个端口而不需要域名，也可直接在 **反向代理** 中新建 **端口直通（免域名）** 规则。

## 动态域名解析（DDNS）

进入 **域名服务 → 动态域名解析（`/edge/ddns`）** 管理 DNS 凭据和同步任务。

当前内置支持 **12 类 DNS 服务商与协议**：Cloudflare、阿里云 DNS、腾讯云 DNS、腾讯云 DNSPod、华为云 DNS、DuckDNS、Porkbun、NameSilo、deSEC、DynDNS2 / No-IP、RFC 2136 动态更新（TSIG）以及通用 Webhook。

### 建议流程

1. 使用服务商提供的最小权限 API Token / Access Key
2. 测试凭据连通性
3. 填写域名、记录类型（A / AAAA / 双栈）、TTL 与检测周期
4. 按地址族分别选择公网 IPv4 / IPv6 获取来源（接口读取、直连探测服务或自定义脚本；直连探测会自动绕过代理与环境 `HTTP_PROXY`）
5. 保存并点击 **立即同步**，核对服务商写入状态与权威 DNS 解析结果一致

DNS 凭据字段在保存后默认掩码展示，留空保存保留原值；管理员可通过查看图标临时核对。创建反向代理规则时，也支持在表单内一键勾选 **同步创建 DDNS 动态解析**，无需跨页重复配置。

::: tip 与自建私网联动
WireGuard 自建私网可直接引用已就绪的 DDNS 任务作为 Endpoint。建议先让 DDNS 通过权威解析验证，再进入 [自建私网](/zh/guide/networking)。
:::

## HTTPS 证书管理

进入 **域名服务 → 证书管理（`/edge/certificates`）**。

### ACME 自动签发

- **DNS-01（默认推荐）**：支持通配符证书（如 `*.example.com`），不要求公网开放 `80` / `443` 端口；支持 Let's Encrypt、ZeroSSL 及自定义 ACME Directory
- **HTTP-01 / TLS-ALPN-01（高级模式）**：分别依赖公网 `80` / `443` 端口直达当前 Edge 引擎，不支持通配符
- 首次接入建议先用 **Staging（仅测试）** 验证流程，通过后再切换 **Production（生产）** 签发正式证书，避免触发 CA 速率限制
- 新建反向代理时，若尚未签发证书，可直接在规则表单中触发 **行内自动签发**

### 导入已有证书与自动部署钩子

- **PEM 导入**：支持直接粘贴 PEM 或从 MSM 受控目录导入，保存前自动校验完整证书链、域名匹配、有效期及私钥一致性；私钥在数据库内加密存储
- **部署钩子（Deploy Hooks）**：证书签发或自动续期成功后，可自动执行最多 8 条联动动作：
  - **本机文件导出（`local_file`）**：将 `fullchain.pem` 与 `privkey.key` 同步写入指定目录，供本机其他服务复用
  - **重启 Docker 容器（`docker_restart`）**：证书更新后自动重启指定名称的容器使新证书生效
  - **Webhook 推送（`webhook`）**：向外部运维接口发送带签名密钥的续期通知（可选附带 PEM 内容）

### 自动续期与保护

- 证书进入续期窗口后自动触发续期，失败按退避策略重试并记录完整签发日志
- 续期失败时保留尚未过期的旧证书继续服务，不中断业务
- 已被路由引用的证书受删除保护，删除前页面会明确列出绑定规则

## 反向代理（L7）

进入 **域名服务 → 反向代理（`/edge/proxies`）**。内置 Edge 网关引擎负责配置校验、原子热重载与失败回滚；默认不主动占用 `80` / `443`，只有在创建并启用使用对应监听端口的规则后才启动监听。

### 五种规则类型与两种访问模式

| 规则类型 | 适用场景 | 关键能力 |
|----------|----------|----------|
| **反向代理** | 将域名或端口请求转发至一个或多个内网服务 | 上游自动发现探测、负载均衡（随机/轮询/最少连接）、主动健康检查、Header 改写、上游 TLS SNI / 自定义 CA |
| **重定向** | 将访问跳转至另一个 URL 或站内路径 | 301/302/307/308 状态码、保留原始路径参数、支持 STUN 动态公网端口变量联动 |
| **静态网站** | 托管静态前端或说明页 | 受控目录静态托管、SPA 前端路由自动回退至 `index.html` |
| **直出响应** | 无需上游直接返回固定响应 | 自定义 HTTP 状态码（100–599）、`Content-Type` 与文本/JSON/维护页 HTML |
| **444 静默断开** | 阻断未授权扫描与默认主机探测 | 零字节直接关闭底层连接，不返回任何响应头或正文 |

创建反向代理时可选择两种对外访问模式：

- **域名反代**：按域名 + 路径前缀匹配，支持同端口 TLS 嗅探跳转、独立 HTTP→HTTPS 跳转端口与优先级排序
- **端口直通（免域名）**：无需域名和 DNS 解析，直接监听指定端口并转发到内网目标，保存前自动检查与 L4 / STUN 等引擎的端口冲突

### 智能全兼容、严格防跨站与 41 款应用预设

面向自托管 Web 与 NAS 应用常见的重定向循环、WebSocket 断连、大文件上传截断与 `403` 拦截问题，反向代理表单内置快捷兼容栏与 **41 款应用预设**：

- **智能全兼容**：一键通用反代模式——自动透传真实 IP 与转发头、智能修正 301/302 `Location` 重定向与 `Set-Cookie` 域名、开启 `-1ms` 零缓冲流式传输（适配 WebSocket / SSE）、关闭网关二次压缩、解除上传体积限制、延长响应超时至 `300s` 并放行内网自签 HTTPS。关闭开关时自动按快照无损恢复原字段，不会覆盖其他独立设置。
- **严格防跨站（对齐 Host）**：一键将发往上游的 `Host` / `Origin` / `Referer` 改写为内网目标地址，解决 qBittorrent、Transmission、Ollama、Syncthing、OpenWrt、Cockpit、ESXi/iDRAC 等应用的 `403` / CSRF 校验拦截。
- **41 款开箱即用应用预设**：覆盖六大分类，并支持在扫描或填写目标端口后自动推荐最佳预设、套用后一键撤销：
  - **通用与协议**：智能全兼容、gRPC / h2c 双向流、SSE / MCP 实时流
  - **NAS 与网盘**：飞牛 fnOS、群晖 DSM、绿联 UGOS、TrueNAS / QNAP / OMV、Unraid、Alist / OpenList、WebDAV、MinIO / S3、Nextcloud、Syncthing
  - **影音与相册**：Immich、Emby、Jellyfin、Plex、Navidrome、Audiobookshelf、qBittorrent、Transmission、Sonarr / Radarr / MoviePilot
  - **虚拟化与运维**：Proxmox VE、ESXi / iDRAC / PiKVM、OpenWrt / iKuai、UniFi OS、Home Assistant、Portainer、Dockge、Docker Registry / Harbor、WebSSH / ttyd、Cockpit、Code-Server、Uptime Kuma、Grafana
  - **AI 与自动化**：Open WebUI / Dify、Ollama LLM API、ComfyUI、n8n / Node-RED
  - **安全与开发**：Vaultwarden、Gitea / Forgejo

### 访问安全姿态与外网密码 / 内网免密

规则的 **安全** 标签提供四档快捷姿态与实时策略矩阵（直观显示内网、外网与恶意爬虫的放行策略）：

1. **标准公网防护**：开启基础爬虫防护、速率限制（RPS）与标准安全响应头
2. **外网密码 · 内网免密**：开启 Basic Auth 账号密码认证（支持一键生成 16 位强密码），同时勾选局域网与指定可信 CIDR 自动免密直通，兼顾家中无感访问与公网安全
3. **仅限内网访问（`lan_only`）**：只允许内网地址访问，公网来源返回 `403` 或 `444` 静默断开
4. **透明直通**：关闭额外安全头与限流，适合需要完整透传协议头的特殊客户端

此外还支持 IP 白名单/永久封禁黑名单、可信代理真实 IP 提取、自定义屏蔽 User-Agent 等细粒度策略。

### 智能微缓存（Turbo Micro-Cache）

在规则的 **高级** 标签可开启路径级智能微缓存：

- 支持按路径模式（如 `/static/*`）分别配置 **缓存**、**强制缓存** 或 **绕过不缓存** 与 TTL
- 面板实时展示当前缓存条目数与占用体积，并支持按路径前缀或全量一键清除

### 批量运维、快照回滚与配置迁移

- **批量操作**：支持批量启用/停用/删除、**批量替换主域名后缀**、批量调整压缩/缓存/日志选项
- **运行快照与回滚**：每次变更保留运行配置版本历史，异常时可在历史抽屉一键回滚
- **导入导出与外部迁移**：支持 MSM 规则包 JSON 导入导出，以及从 **Nginx Proxy Manager (NPM)**、**Caddyfile** 等外部反代配置迁移导入（默认以停用状态导入，核对端口与证书后再批量启用）

### 上游目标地址建议

- **MSM 与目标同机**：填写目标服务实际监听地址和端口
- **MSM 运行在 Docker Bridge 模式**：不要用 `127.0.0.1` 指代宿主机服务，请使用宿主机 LAN IP 或同网络容器名
- **上游使用自签名 HTTPS**：优先配置上游 CA 与 SNI；确为可信内网服务时再启用跳过证书校验

## 端口转发（L4）与 443 零解密分流

进入 **域名服务 → 端口转发（`/edge/forwards`）**，面向非 HTTP 协议（SSH、RDP、数据库、游戏联机、WireGuard 等）或端口复用场景提供纯 Go 四层转发：

- **高速 TCP / UDP 转发**：支持单端口或连续端口段映射、双栈 **IPv6 → IPv4 桥接**、TCP **PROXY Protocol v1/v2** 透传、单 IP 最大并发限制与 IP 黑白名单
- **443 零解密多协议分流（SNI Mux）**：在不解密 TLS 证书的前提下，通过首包协议嗅探将进入同一端口（如 `443`）的流量按优先级精准分流至不同后端：
  - 支持识别 **TLS（SNI 精确/通配符域名与 ALPN）**、**HTTP（Host）**、**SSH**、**RDP**、**SOCKS5** 以及 **等待超时兜底**（适配 VNC / MySQL 等服务端先发包协议）
  - 内置 **「回家节点 + 本地 HTTPS 网关共用 443」** 一键模板，方便在仅有单个公网 443 端口时并存多种服务
- **一键升级为反向代理**：已有 L4 转发规则可一键转为 L7 反向代理以获得域名匹配、HTTPS 证书与访问控制

## STUN 内网穿透（NAT1 直连）

进入 **域名服务 → 穿透隧道（`/edge/tunnels`）**。面向无公网 IPv4 但宽带处于全锥形 NAT（NAT1）环境的用户：

- **RFC 5389 零中转打洞**：无需公网中转服务器即可跑满家庭宽带上行，TCP 使用 `SO_REUSEPORT` 同源端口复用，内置直连 STUN 探测池并自动绕过透明代理
- **UPnP / NAT-PMP 自动映射**：自动向主路由申请端口映射，并实时检测是否存在多层 NAT（Double NAT）
- **快捷场景模板**：内置 NAS 桌面直连、远程桌面 RDP、游戏联机 UDP、SSH 终端四种预设
- **地址变化自动联动**：公网 IP 或映射端口变动时，自动更新关联的 **DDNS 任务**、同步重写 **免端口 302 域名跳转规则**（创建通道时可一键自动生成绑定的免端口访问域名），或通过动态模板变量推送 Webhook

## 全链路实时拓扑与诊断

- **全链路实时流量拓扑（`/edge/topology`）**：四列可视化呈现 **公网入口 WAN → 监听与穿透入口 → 域名与协议路由 → 上游服务与容器** 的实时状态：
  - 实时汇总 QPS、入站/出站带宽、活跃并发连接与节点健康度（默认每 3 秒自动刷新）
  - 支持按 L7 / L4 / STUN / Cloudflare / 告警分类筛选、仅看活跃流量、紧凑视图与点击节点打开实时检查器
  - 右上角提供 **一键隐私打码**，脱敏公网 IP 与域名便于截图排错
- **分阶段发布诊断**：
  1. **DDNS 诊断**：核对公网 IP 探测来源、DNS 写入记录与权威解析结果
  2. **证书日志与预检**：检查 ACME 挑战阶段、域名覆盖、有效期与部署钩子执行结果
  3. **6 阶段链路诊断**：一键并行核查公网 IP、权威 DNS、HTTPS 证书、网关运行态、目标服务与最终域名访问
  4. **独立访问日志与健康日志**：访问日志支持按状态码、关键词与延迟筛选；健康检查历史独立存储便于溯源

## 安全建议

- DNS 凭据仅授予对应域名的最小操作权限
- 公网发布家庭管理面板时，优先使用 **外网密码 · 内网免密** 或改用 [自建私网](/zh/guide/networking) / [远程回家](/zh/guide/home)
- Docker 部署别忘记映射路由或转发实际使用的监听端口
- 删除证书或上游前先检查拓扑与绑定引用关系
