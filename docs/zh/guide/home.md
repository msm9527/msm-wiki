# 远程回家

**远程回家**用于在家庭端的代理核心中创建公网入站，并将家庭网段与现有代理订阅融合为可直接导入手机、平板与电脑的完整配置文件，让外出设备通过公网 IP 或 DDNS 安全访问家庭局域网。

MSM 已将远程回家与异地组网整合为统一的 **回家与私网** 协同工作台，由三个页面分工协作（旧地址 `/proxy/home` 会自动重定向）：

| 页面 | 路由 | 职责 |
|------|------|------|
| **自建私网** | `/networking` | 管理 WireGuard、EasyTier、Tailscale 三引擎点对点私网与成员设备 |
| **代理协议回家** | `/networking/inbound` | 配置 Clash / Sing-Box 多协议公网入站监听器、TLS 证书与运行检查 |
| **终端配发** | `/networking/delivery` | 一键生成五端融合配置、二维码、可撤销分享短链、轻量节点与防冲突直连规则 |

::: warning 授权与公网暴露
“远程回家”只生成和管理用户自建的 Clash / Sing-Box 入站配置，MSM 不提供节点、订阅、远程接入中继或网络接入服务。仅可将入站开放给你本人或已授权的设备，并只发布自有或已授权的网段和服务。请使用强随机凭据、最小端口和可撤销配置，不得将其用作未授权访问的跳板。
:::

这种方式需要家庭网络具备可从公网到达的地址和端口映射（或配合 Edge 网关的 STUN NAT1 穿透）。若没有公网 IP、处于多层 CGNAT，或不希望开放端口，请改用 [Cloudflare 内网穿透](/zh/guide/cloudflare) 发布 Web 页面，或用 [自建私网](/zh/guide/networking) 访问整个家庭网段。
:::

## 工作原理

```text
外出设备（手机 / 平板 / 电脑）
  └─ 融合配置或独立回家节点（Clash / Sing-Box / Loon / Shadowrocket / Surge）
       └─ 公网 IP / DDNS:公网端口
            └─ 路由器端口转发与防火墙（或 Edge 443 SNI 复用）
                 └─ MSM 当前代理核心的入站监听器
                      └─ DIRECT 访问家庭局域网 CIDR（或全流量经家庭出口）
```

## 支持的入站协议

页面支持为 Clash 或 Sing-Box（Pro）**同时创建多个入站监听器**，每个监听器独立选择以下协议：

| 协议 | 认证信息 | TLS | 主要传输 |
|------|----------|-----|----------|
| **Shadowsocks** | 密码与加密方式 | 不需要 | TCP，可同时启用 UDP |
| **VLESS** | UUID | 需要 | TCP |
| **Trojan** | 密码 | 需要 | TCP |
| **AnyTLS** | 密码 | 需要 | TCP |
| **Hysteria2** | 密码 | 需要 | UDP / HTTP/3 |
| **TUIC v5** | UUID 与密码 | 需要 | UDP / HTTP/3 |

每种协议在同一核心内最多保留一套活动监听器，所有监听器必须使用不同端口。保存前 MSM 会自动检查重复端口、凭据完整性、证书可用性及当前核心能力。

## 准备条件

- Clash 或 Sing-Box（Pro）已在 **应用商店** 安装并正常运行
- 家庭宽带有公网 IPv4、可入站 IPv6，或其他可到达入口
- 路由器可以配置端口转发和防火墙
- 已确认家庭 LAN 网段，例如 `192.168.1.0/24`
- 动态公网地址建议先配置 [域名服务中的 DDNS](/zh/guide/domain-services#动态域名解析-ddns)

## 配置回家入站（`/networking/inbound`）

进入 **回家与私网 → 代理协议回家（`/networking/inbound`）**。顶部工具栏提供 **一键隐私模式**（截图排错时自动脱敏公网域名与 IP）、双核心切换开关（已同时安装 Clash 与 Sing-Box 时可见）以及配置预览弹窗入口。

### 跨核心同步与网段联动

- **跨核心一键同步**：若你已在 Clash 或 Sing-Box 其中一个核心配置好回家入站，切换到另一个尚未配置的核心时，页顶横幅会提示**一键同步入站参数**，方便后续切换核心时无缝衔接
- **一键合并组网网段**：若已在 [自建私网](/zh/guide/networking) 中发布了家庭局域网路由，页面会自动检测差异并提供一键合并按钮

### 配置步骤

1. 在顶部 **准备情况** 与摘要条中确认当前核心状态、监听器、公网入口与家庭网段是否齐全
2. 在 **快速网络配置** 中填写公网 IP 或 DDNS（支持自动匹配已有 DDNS 任务；只填域名或 IP，不要加协议、路径或端口）
3. 核对家庭内网 CIDR，每行一个
4. 添加一个或多个监听器，分别选择协议、启用状态和端口
5. 按协议填写密码或 UUID（可一键生成强随机凭据）
6. 使用 TLS 的协议优先直接选择 **域名服务 → 证书管理** 中已签发、未过期的生产证书；MSM 会自动将证书同步到当前核心的安全目录
7. 先点击校验或查看 **配置预览与指南**，确认无误后点击 **保存并应用**，最后执行 **运行检查**

高级监听设置中可自定义监听器名称和监听地址；Shadowsocks 可选择加密方式及是否开启 UDP。`::` 会监听 IPv6 并在系统支持时同时接受 IPv4。客户端 TLS 域名用于 SNI 与证书校验，应填写证书实际覆盖的完整域名；使用生产证书时不要开启“跳过证书校验”。

![远程回家监听器：协议、监听端口、凭据和使用步骤](/images/ui/proxy-remote-home-listener.jpg)

> 图中示例使用 Shadowsocks，路由器需按提示映射 TCP 和 UDP。切换到 VLESS、Trojan、AnyTLS、Hysteria2 或 TUIC v5 后，表单与转发协议会同步更新，请以页面生成的步骤为准。

::: warning TLS 文件必须能被代理核心读取
VLESS、Trojan、AnyTLS、Hysteria2 和 TUIC v5 的证书与私钥字段为服务端文件路径，并非直接粘贴 PEM 正文。容器安装时，路径必须位于代理核心容器实际可见的挂载目录。
:::

## 配置端口转发

### 二进制或宿主机安装

在家庭主路由上，将公网侧所选端口转发到 MSM 主机相同的监听端口，并在路由器和主机防火墙中放行：

- **Shadowsocks**：按页面设置转发 TCP 或 TCP + UDP
- **VLESS / Trojan / AnyTLS**：转发 TCP
- **Hysteria2 / TUIC v5**：转发 UDP

::: tip 公网仅有 443 端口？
如果公网只开放了 `443` 端口，可在 [域名服务 → 端口转发](/zh/guide/domain-services#端口转发-l4-与-443-零解密分流) 中使用 **443 零解密 SNI 分流**，让回家节点与本地 HTTPS 反向代理共用同一个 `443` 端口。
:::

### Docker 安装

链路多一层宿主机到容器的端口映射：

```text
公网端口 → MSM 宿主机发布端口 → 容器目标端口 → 代理核心监听器
```

页面会自动展示已检测到的 Docker 映射：代理核心监听端口必须与容器 **目标端口** 一致，外出客户端与路由器端口转发则使用宿主机的 **发布端口**。若映射仅绑定到 `127.0.0.1`，外网设备无法连接，修改 Compose 端口后请重建容器再重新检测。

## 终端配发工作台（`/networking/delivery`）

入站保存并应用后，进入 **回家与私网 → 终端配发（`/networking/delivery`）**。页面顶部以 **通道就绪总览** 实时汇总代理回家入站、异地组网隧道、家庭局域网段与活跃分享短链状态，并提供三种面向不同设备的配发模式：

### 1. 手机 / 平板 · 单 App 融合包（推荐 · 省 VPN 槽位） {#mobile-bundle}

将当前运行核心的代理订阅、回家入站节点，以及可选的 **WireGuard（`WG-HOME`）** 隧道整合进同一份客户端配置，避免移动系统同时开启多个 VPN 互相抢占槽位。

#### 跨核心五端自动转换（可一次多选）

MSM 内置跨核心转换引擎，无论当前家庭端运行 Clash、Clash Smart 还是 Sing-Box，均可一次勾选生成以下五种客户端格式：

| 客户端格式 | 适用客户端 | 转换特性 |
|------------|------------|----------|
| **Clash / Clash Meta** | FlClash、Clash Verge、Stash 等标准客户端 | 自动剥离 Smart 专属字段，完整保留订阅、策略组、DNS 与分流规则 |
| **Clash Smart** | 内置 Smart 内核的移动端客户端 | 保留 `type: smart` 策略组与智能探测参数，承接当前订阅与分流 |
| **Sing-Box reF1nd** | Sing-Box reF1nd 客户端 | 保留远程订阅 `providers`、自动更新周期与 `.srs` 规则集，节点后续由客户端自动刷新 |
| **官方 Sing-Box** | App Store / Google Play 官方 Sing-Box 客户端 | 自动拉取订阅并展开为原生静态 `outbounds`，移除仅 Linux 字段（如 `default_mark`），避免 iOS / Android / macOS 启动失败 |
| **Loon（`.lcf`）** | iOS / macOS / tvOS Loon | 自动转换 `[Remote Proxy]`、`[Remote Filter]`、`.lsr` 规则集与防 TUN 跳过局域网规则，支持一键唤起 Loon 导入 |

::: info 关于 Loon 与纯 TUIC 入站
Loon 原生不支持纯 TUIC 回家入站。若当前仅启用了 TUIC 监听器，页面会自动提示补充 Hysteria2 / VLESS / AnyTLS / Trojan / Shadowsocks 监听器，或勾选 WireGuard 融合通道。
:::

::: info 关于官方 Sing-Box 与本地规则集
官方 Sing-Box 不原生支持 Clash 的 `proxy-providers`。当源配置包含仅存在于服务器本地的订阅或规则集而无法打包为单文件时，页面会明确禁用对应格式并给出原因，而不是生成无法启动的 JSON。
:::

#### 两种设备流量策略

- **仅回家网段（默认）**：仅将家庭局域网 CIDR 导向回家通道，其余访问沿用设备原有代理与直连规则
- **全流量经家庭出口**：家庭内网与全部互联网流量均经家庭端转发，适合外出时统一使用家庭出口 IP

#### 二维码、HTTPS 入口校验与可撤销短链

- 二维码对应可下载完整配置的短链接，默认沿用当前浏览器访问 MSM 的协议、域名和端口，也可在「自定义公网入口」中调整
- 部分 Android 客户端（如 FlClash）仅接受域名形式的 **HTTPS** 订阅链接；页面会自动检测当前入口协议并给出明确提醒
- 有效期与最多下载次数支持预设值、自定义值，以及 **永久有效** / **次数不限**；页面下方提供 **活跃分享短链** 卡片，可随时查看剩余次数、到期时间并一键撤销
- 永久链接相当于长期 Bearer 凭据，仅限个人可信设备使用，不再需要时请立即撤销

### 2. 轻量节点扫码与规则片段 {#lightweight-nodes}

适合使用 Shadowrocket、Surge、Loon 等客户端且**不希望覆盖现有订阅**的场景：

- 单独复制或扫码导入各个协议的回家节点 URI
- 一键复制针对家庭网段的 Clash / Sing-Box / Surge 分流回家规则片段

### 3. 电脑 / NAS · 原生组网与防冲突 {#desktop-mesh}

适合在笔记本、台式机或异地 NAS 上同时使用自建私网与代理软件的场景：

- 直接为已启用的 WireGuard / EasyTier / Tailscale 签发原生设备接入凭证
- 自动汇总全部已发布家庭网段，一键复制 **防代理 TUN 抢路由直连规则**（支持 Clash / Sing-Box / Surge），并附带内网私有域名 `fake-ip-filter` 建议

## 运行检查

保存并应用后，在 **代理协议回家（`/networking/inbound`）** 点击 **运行检查**。MSM 会依次核对：

1. 当前核心的完整配置是否通过语法与语义校验
2. 当前代理核心服务是否处于运行态
3. 所选协议要求的 TCP、UDP 或 TCP + UDP 监听端口是否已由代理核心持有
4. 公网入口与家庭网段信息是否填写完整

::: danger 本机检查不等于公网可达
MSM 无法从家庭网络外部证明路由器端口转发、防火墙、运营商 CGNAT 或公网路由已经生效。最终验收必须关闭手机 Wi-Fi（使用蜂窝网络），或从真正位于外网的设备访问家庭 LAN 地址。
:::

## 配置安全与回滚

- 保存前使用当前活动核心校验完整配置
- 核心正在运行时，“保存并应用”会重载或重启核心并等待监听器就绪
- 应用失败自动恢复原配置，并尝试恢复旧核心运行状态
- 密码、UUID 与下载短链均包含敏感接入凭据，请勿粘贴到公开聊天、日志或工单中
- 重新生成密码或 UUID 后，已导入旧凭据的设备需重新配发或更新节点

## 常见问题

### 本机检查通过，但外网无法连接

- 确认宽带是否真正拥有可入站公网地址（出口 IP 不等于公网可达）
- 按协议核对路由器转发类型：TCP、UDP 或 TCP + UDP
- 检查宿主机防火墙、上级光猫桥接/DMZ 与安全组
- Docker 部署请核对宿主机发布端口、容器目标端口与监听器端口是否一致
- 务必使用家庭网络之外的蜂窝网络进行真实测试

### 可以连接，但访问不到家中设备

- 核对客户端规则中的家庭 LAN CIDR 是否覆盖目标设备网段
- 确认家庭网段规则位于兜底规则之前
- 检查家庭设备自身防火墙与回程路由
- 存在多个 LAN 网段时请逐行添加到配置中

### 切换代理核心后怎么办？

切换到另一个代理核心后，进入 **代理协议回家（`/networking/inbound`）**。若新核心尚未配置入站，可直接点击页顶 **跨核心同步** 横幅导入原核心参数，保存应用并执行运行检查即可。
