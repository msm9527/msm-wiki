# 授权管理

MSM 使用许可证能力控制高级模块和写操作。是否能执行一个操作，不只取决于“是否 Pro”，还会同时检查具体能力、功能开关、用户角色和授权证明。

![授权管理：标准版与 Pro 功能对比、支持与激活入口](/images/ui/license-management.png)

未激活时，页面仍会完整展示标准版 / Pro 功能对比，并提供 **支持项目**、**已有授权码，立即激活**、Telegram 频道和交流群入口。查看者可以阅读授权状态和版本功能，但激活、更换或撤销授权只对管理员开放。

## 权限判定顺序

1. **功能开关**：模块 API 是否启用
2. **基础 Pro**：是否允许进入 Pro 工具模块
3. **细分能力**：例如代理管理、配置写入、用户管理
4. **用户角色**：管理员、操作员、查看者
5. **授权证明**：部分读取或高风险写操作要求有效本机 Proof
6. **在线授权**：用户、Token、配置等高风险变更可能要求短期在线授权

因此，看到菜单不代表当前账号一定能执行其中所有操作。

## 主要许可证能力

| 能力 | 典型用途 |
|------|----------|
| **基础 Pro (`pro`)** | 域名服务、Cloudflare、自建私网、Docker 管理、网络工具、MosDNS 高级版本 / 配置功能 |
| **代理管理 (`proxy.manage`)** | Mihomo Smart、核心安装 / 版本切换、代理配置和高级策略 |
| **配置写入 (`config.write`)** | 通用配置树的创建、编辑、上传、删除、复制与重命名 |
| **增强历史 (`config_history_enhanced`)** | 创建历史、回滚、稳定标记和删除历史 |
| **服务控制 (`service.control`)** | 受保护的服务启停与重启操作 |
| **设置写入 (`settings.write`)** | 保存用户或系统设置中的受保护参数 |
| **用户管理 (`users.manage`)** | 创建、修改、停用、删除用户及重置密码 |
| **API Token (`api_tokens.access/manage`)** | 查看、创建、更新与撤销长期令牌 |
| **仪表盘定制** | 保存自定义卡片布局 |
| **背景定制** | 上传和管理界面背景 |

最终能力列表以 **授权管理** 页面当前返回值为准。不同许可证可能只授予其中一部分，不要仅根据文档推断权益。

## 在 Web 界面激活

1. 使用管理员账号进入 **授权管理**
2. 点击 **已有授权码，立即激活**；已有异常授权时使用 **更换授权**
3. 输入授权码并确认激活
4. 点击刷新状态，确认版本、有效期和所需能力已经解锁

激活完成后，如果入口仍未出现，检查 **系统设置 → 功能开关** 和当前用户角色。

如需购买、查看版本公告或联系社区，点击页面中的 **支持与社群**，使用 MSM 提供的官方跳转入口；不要相信聊天中来历不明的收款或授权链接。

## 命令行管理

```bash
# 查看授权状态
msm license status

# JSON 格式查看状态
msm license status --json

# 获取硬件指纹
msm license fingerprint

# 激活
msm license activate --code '<激活码>'

# 取消激活
msm license deactivate
```

不要把激活码、完整授权 JSON 或设备敏感信息粘贴到公开日志和工单。

## 授权状态

常见字段包括：

- 激活状态
- 是否 Pro
- 激活时间
- 到期时间
- 硬件指纹
- 已授予能力
- 本机 Proof / 联网状态相关提示

许可证到期、授权心跳失败或本机 Proof 失效时，部分只读页面仍可能显示缓存状态，但受保护操作会被后端拒绝。

## 迁移设备

1. 使用管理员账号在旧设备打开 **授权管理**
2. 点击 **取消激活**，输入授权关联邮箱和授权码完成自助撤销
3. 在新设备输入同一可用授权码重新激活
4. 刷新授权状态并检查能力
5. 恢复配置后逐项验证 Pro 模块

自助撤销不会通过公网 IP 猜测或代替验证，必须同时提供授权邮箱和授权码。更换主板、系统环境或关键硬件可能改变指纹；无法访问旧设备或遗失材料时，通过授权页的官方支持入口处理。

## 常见错误

### `PRO_REQUIRED`

当前许可证缺少基础 Pro 或具体能力。查看授权管理页的能力列表。

### `ONLINE_AUTH_REQUIRED`

该高风险操作需要短期在线授权。检查 MSM 到授权服务的网络、系统时间和许可证状态后重试。

### `ACTION_ATTESTATION_REQUIRED`

请求缺少与本次操作匹配的授权证明。刷新页面重新发起，不要复用旧请求或绕过正常界面流程。

### 已激活但模块入口不见了

- 检查系统功能开关
- 确认当前账号角色
- 退出后重新登录以刷新能力
- 检查许可证是否到期、Proof 是否有效
