# 系统设置

系统设置集中管理运行参数、HTTPS、Pro 模块开关、外观、备份和更新。管理员可以修改系统级配置；其他角色能看到的标签和操作按权限减少。

![系统管理：运行参数、HTTPS 与 Pro 组件开关](/images/ui/settings-system.png)

## 页面标签

| 标签 / 区域 | 用途 |
|-------------|------|
| **系统管理** | 运行参数、HTTPS、下载镜像源、功能开关、API Token 管理与管理员工具 |
| **外观设置** | 语言、主题、简洁/高级模式、导航布局与仪表盘风格定制 |
| **通知渠道** | 配置运维告警与系统事件推送渠道并发送测试消息 |
| **备份恢复** | v3 分级备份、自动备份策略（默认保留 3 份）、存储位置与恢复（管理员） |
| **存储清理** | 查看运行目录、日志、缓存与备份的磁盘占用，支持清理前预览（管理员） |
| **系统更新** | MSM 本体与核心组件版本、稳定/Beta 通道与更新操作（管理员） |
| **重置与卸载** | 系统重置或执行受控的 Web 端安全卸载（管理员，高风险） |

个人资料位于 **用户管理 → 个人中心**；授权详情从侧边栏 **授权管理** 进入；模块安装与卸载在 **应用商店（`/apps`）** 中管理。

## 系统管理

### 时区与会话

- 设置服务端时区，影响日志、任务和证书时间显示
- 设置登录 Token 有效时间，页面范围为 1–720 小时，默认 24 小时
- 设置日志输出级别和 Web 管理端口
- 保存时区后检查计划任务和日志时间是否一致

### HTTPS

MSM 支持三种证书处理方式：

1. 继续使用当前证书
2. 上传 PEM 证书与私钥
3. 自动生成局域网自签名证书

上传时必须同时提供证书和私钥。自动生成的证书包含本机可识别地址，适合局域网起步，但浏览器不会默认信任。

启停 HTTPS、替换证书或修改相关监听参数通常需要重启 MSM。应用前记录新的访问协议和端口，避免把自己锁在管理界面之外。

## 功能开关

Pro 工具模块默认可以在设置中管理：

| 开关 | 影响 |
|------|------|
| **域名服务** | DDNS、证书和反向代理入口与 API |
| **Docker 管理** | Docker 资源、节点与操作 API；保存后立即生效 |
| **内网穿透与自建私网** | Cloudflare Tunnel Web 发布，以及 EasyTier、Tailscale、WireGuard 私网入口与 API |
| **网络工具** | 网络诊断入口与 API |

管理员只有具备对应 Pro 模块管理能力时才能修改开关。关闭模块会隐藏导航并停用 API，但不会自动删除已经创建的凭据、配置或远端资源。

Clash Smart 也有独立的系统能力开关；是否可选还会检查 Pro 的 `proxy.manage` 能力。

::: warning 关闭模块前
先停止仍在运行的连接器、私网或相关任务，并记录外部资源。功能开关不是资源清理按钮。
:::

## 外观设置

![外观设置：主题、语言、菜单顺序与 Pro 视觉定制](/images/ui/settings-appearance.png)

- **语言与主题**：支持简体中文 / English，明亮、暗色和跟随系统主题
- **工作台模式**：支持在 **简洁模式** 与 **高级模式** 间切换，按使用习惯收起或展开高阶参数
- **布局与风格**：支持多种导航布局与仪表盘卡片风格，以及菜单顺序和背景定制（按许可证能力开放）

外观偏好按用户保存在个人设置中，不影响其他账号或服务端运行配置。

## 下载镜像源与通知渠道

- **下载镜像源**：在网络访问 GitHub 较慢的环境中，可切换为国内加速镜像源或配置自定义下载代理，统一作用于核心组件安装与系统更新
- **通知渠道（`/notify`）**：支持配置消息推送渠道，用于接收系统告警、证书续期异常、备份结果或更新提醒，保存前可直接点击测试推送验证可达性

## 备份恢复

![备份恢复：创建、配置、导入以及带版本快照的备份列表](/images/ui/settings-backup.png)

> 截图中的 `mihomo` 是备份版本快照保留的内核技术标识，对应文档中的 **Clash**。

备份可包含 MSM 数据库、MosDNS、Clash、Sing-Box 和其他模块配置。建议：

- 重大升级或代理核心切换前创建备份
- 备份文件离机保存并加密
- 恢复前核对模块、版本和目标主机
- 恢复后逐项检查服务与网络状态

详见 [备份恢复](/zh/guide/backup-restore)。

## 系统更新

![系统更新：MSM 设置、更新前备份、组件版本和版本历史](/images/ui/settings-update.png)

> 组件卡片面向用户显示 **Clash**；部分较旧的说明文字可能仍显示内核技术标识。

系统更新页管理：

- 稳定版或 Beta 通道
- MSM 本体版本
- MosDNS、Clash 与 Sing-Box 组件
- 下载源、检查与安装进度

更新会执行下载、校验、持久化和运行时切换。不要在更新进度中手动替换二进制或终止进程。详见 [更新升级](/zh/guide/update)。

## API Token 管理

API Token 入口位于 **系统设置 → 系统管理** 页面下方，而不是用户管理或授权管理页面。创建、修改和撤销 Token 需要管理员角色及许可证中的 API Token 管理能力。

![标准版中的 API Token 管理能力提示](/images/ui/settings-api-token.png)

Token 明文只应在创建后立即保存到受保护的密码库或 Secret 管理器；不要放入 Git、截图、日志或聊天记录。撤销 Token 后，使用它的自动化任务会立即失去访问能力。

## 重置系统与安全卸载

![重置系统页：清除配置和用户数据并重新进入初始化](/images/ui/settings-reset.png)

**重置系统**与 **Web 端卸载**均属于破坏性高风险操作。执行前务必确认：

1. 已创建并下载一份可用的离机备份
2. 已记录当前管理端口、HTTPS、管理员凭据与网络配置
3. 已确认外部 Tunnel、DNS 记录、Docker Agent 节点是否需要同步解绑
4. 如仅需修复单个模块异常，优先使用诊断、日志、配置历史或选择性恢复，而不是重置全站

- **重置系统**：清除系统配置与用户数据，并重新进入初始化向导
- **安全卸载（非 Docker 部署）**：提供卸载前影响目录预览，确认后自动停止托管服务、尝试恢复宿主机 DNS 并引导至卸载回执页（`/uninstall`）；Docker 部署请直接通过 `docker compose down` 移除容器

## 配置生效边界

- 功能开关通常立即生效
- HTTPS、监听和部分运行参数需要重启
- 代理核心参数应从 **代理服务** 修改
- MosDNS 参数应从 **DNS服务** 修改
- 域名、Cloudflare Tunnel、自建私网和 Docker 数据应从各自模块管理
