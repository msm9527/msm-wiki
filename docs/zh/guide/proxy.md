# 统一代理服务

新版 MSM 将 Mihomo 与 Sing-Box 收拢到同一个 **代理服务** 菜单。无论当前使用哪个核心，节点、规则、连接、配置和日志入口都保持不变；页面会根据当前核心自动展示它支持的能力。

![代理服务概览：代理方案、实时流量、网络信息与运行配置](/images/ui/proxy-overview.jpg)

## 当前可选代理方案

| 方案 | 适合场景 | 权限与说明 |
|------|----------|------------|
| **官方 Mihomo** | 追求成熟兼容性；可使用 Meta 稳定版或 Alpha 预览版 | 基础方案 |
| **Mihomo Smart** | 使用 Smart 核心、专属配置模板和 Smart 策略组 | 需要 Pro 的 `proxy.manage` 能力 |
| **Sing-Box** | 使用 reF1nd Sing-Box 核心及原生 JSON 配置 | 基础方案 |

## 统一子菜单

| 子菜单 | 主要用途 | 常见权限 |
|--------|----------|----------|
| **概览** | 查看活动核心、版本、运行状态、流量和方案切换入口 | 查看 |
| **远程回家** | 为当前 Mihomo 或 Sing-Box 核心配置公网入站，并生成客户端配置 | 管理员、操作员 |
| **代理节点** | 管理订阅、节点和策略组，执行延迟测试 | 查看或操作 |
| **规则管理** | 查看并维护当前核心的分流规则 | 查看或操作 |
| **高级设置** | 可视化维护策略、规则和核心高级参数 | Pro；管理员、操作员 |
| **连接管理** | 实时查看连接、规则命中、节点和流量，按权限关闭连接 | 查看或操作 |
| **配置编辑** | 编辑完整 YAML / JSON，校验并应用 | Pro 配置管理能力 |
| **日志查看** | 查看当前核心的运行日志和错误 | 查看 |

角色与许可证能力会同时生效。查看者通常只能读取状态；切换代理方案仅允许管理员执行。

## 安全切换代理方案

进入 **代理服务 → 概览**，在方案卡片中选择目标核心。确认后 MSM 会执行完整切换事务：

1. **准备目标核心**：检查或下载目标二进制，确认核心家族与配置匹配
2. **迁移并启动**：保留订阅和网络设置，停止旧核心并启动目标核心
3. **应用网络规则**：重新确认透明代理、DNS 模式和系统网络规则
4. **验证控制器**：检查控制器、策略组、订阅与配置接口是否可用
5. **同步最终状态**：刷新页面并将目标方案标记为就绪

切换时已有代理连接可能短暂中断。不要在进度窗口运行期间重复刷新、重启服务或手动修改进程。

::: warning 切换失败时
先阅读进度窗口中失败的阶段，再查看 **代理服务 → 日志查看** 和 **系统诊断**。MSM 会尽量保留原有订阅、配置与网络状态，但仍建议在首次跨核心切换前创建备份。
:::

## 官方 Mihomo 与 Smart 核心切换

官方 Mihomo 内还可选择 Meta 稳定版或 Alpha 预览版。Mihomo Smart 使用不同的核心家族、配置模板和策略组字段，MSM 会在切换前检查二进制版本与配置是否匹配，并清理不属于目标核心的 Smart 专用字段。

不要把 Smart 配置直接交给 Meta / Alpha 核心运行，也不要只替换二进制而跳过 MSM 的切换流程。

## 订阅、节点与策略组

![代理节点：策略组、节点筛选、模式切换和延迟测试](/images/ui/proxy-nodes.jpg)

建议按以下顺序操作：

1. 在 **代理节点** 添加或更新订阅
2. 对订阅或节点执行延迟测试
3. 在策略组中选择实际使用的节点
4. 在 **规则管理** 检查规则最终指向的策略组
5. 在 **连接管理** 发起真实访问并确认规则、策略组和节点

跨核心切换时，MSM 会转换可兼容的订阅与控制信息。个别目标核心不支持的 Provider 类型、规则集格式或字段会在界面中标明；不要忽略这些提示。

## 配置编辑与生效

- Mihomo 使用 YAML；Sing-Box 使用 JSON
- 结构化编辑只修改对应字段，未编辑的原生字段应继续保留
- 保存前先执行配置校验
- 正在运行的核心需要按页面提示重启或应用
- 应用失败时查看回滚提示与最近日志

新版配置写入会尽量保留 YAML 的注释和字段顺序，但在核心格式转换、自动迁移或结构化重建时，仍应以保存后的差异为准。

## 常见问题

### 为什么旧的 `/mihomo` 或 `/singbox` 地址跳回统一页面？

旧地址只作为兼容入口。新版正式路径位于 `/proxy/*`，进入旧地址后会先同步活动核心，再跳转到统一代理页面。

### 为什么我不能切换方案？

代理方案切换仅允许管理员执行。Mihomo Smart 还需要启用对应功能开关，并具备 Pro 的代理管理能力。

### 为什么两个核心都显示正在运行？

这属于异常状态。不要继续切换或同时接管网络；先在进程管理和日志中确认哪个核心应当保留，再恢复为单一活动核心。

### 切换后节点暂时不可用怎么办？

先查看进度中的控制器验证结果。目标核心不支持的订阅会被跳过并给出提示；修正订阅格式后重新更新和测速。
