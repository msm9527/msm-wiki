## 用户配置与操作风险

MSM 可执行高权限系统和网络操作。用户应对自己输入、导入或选择的以下内容负责：

- 网络接口、DNS、FakeIP、路由、TUN、nftables 和防火墙参数
- 节点、订阅、规则、配置模板、软件核心和第三方下载源
- 域名、DNS API 凭据、证书、私钥、反向代理上游和公网暴露策略
- Docker Socket、Agent、容器命令、存储卷、网络、Compose/Stack 和镜像来源
- 私网路由、远程访问端口、Peer、密钥、共享配置与访问权限

即使界面显示验证成功，也不代表完成了用户组织所需的安全审核、业务验收、容灾演练或法律审查。
