# Shadowsocks 回家

“回家”用于在家庭端的当前代理核心中创建 Shadowsocks 入站，让外出设备通过公网 IP 或 DDNS 访问家庭局域网。Mihomo 与 Sing-Box 都使用同一个 **代理服务 → 回家** 页面。

::: warning 先确认适用场景
这种方式需要家庭网络具备可从公网到达的地址和端口映射。若没有公网 IP、处于 CGNAT，或不希望开放端口，请改用 [Cloudflare 云端私网](/zh/guide/cloudflare) 或 [自建私网](/zh/guide/networking)。
:::

## 工作原理

```text
外出设备
  └─ Shadowsocks 客户端节点
       └─ 公网 IP / DDNS:端口
            └─ 路由器 TCP + UDP 端口转发
                 └─ MSM 当前代理核心的 Shadowsocks 入站
                      └─ DIRECT 访问家庭局域网 CIDR
```

## 准备条件

- Mihomo 或 Sing-Box 已安装并正常运行
- 家庭宽带有公网 IPv4、可入站 IPv6，或其他可到达入口
- 路由器可以配置端口转发和防火墙
- 已确认家庭 LAN 网段，例如 `192.168.1.0/24`
- 动态公网地址建议先配置 [域名服务中的 DDNS](/zh/guide/domain-services#动态域名解析)

## 配置服务端

进入 **代理服务 → 回家**：

1. 点击 **自动检测**，查看出口地址和家庭网段建议
2. 启用 **回家服务**
3. 填写公网 IP 或 DDNS，只填写域名或 IP，不要加协议、路径或端口
4. 设置监听端口；默认模板使用 `31303`
5. 生成高强度密码
6. 核对家庭内网 CIDR，每行一个
7. 建议保持 UDP 启用
8. 先点击 **校验配置**，再点击 **保存并应用**

高级监听设置中可以修改监听器名称、监听地址和加密方式。`::` 会监听 IPv6，并在系统支持时接受 IPv4；客户端的端口、密码和加密方式必须完全一致。

## 配置端口转发

### 二进制或宿主机安装

在家庭主路由上，将公网侧所选端口的 **TCP 和 UDP** 都转发到 MSM 主机相同的监听端口，并在路由器和主机防火墙中放行。

### Docker 安装

链路多一层端口映射：

```text
公网端口 → MSM 宿主机发布端口 → 容器目标端口 → 代理核心监听器
```

页面会显示已检测到的 Docker 映射。代理核心监听端口必须与容器的 **目标端口** 一致；外出客户端和路由器端口转发使用宿主机的 **发布端口**。

如果映射只绑定到 `127.0.0.1`，局域网和公网设备无法连接。修改 Compose 端口后需要重建容器，再回到页面重新检测。

## 导入客户端配置

配置完整后，页面会生成：

- 当前 Mihomo 或 Sing-Box 核心的服务端配置预览
- 可复制到外出设备 Mihomo 配置中的客户端 YAML

客户端规则应让家庭 LAN CIDR 命中生成的回家节点，并放在 `MATCH` 等兜底规则之前。家庭端的监听器会使用 `DIRECT` 访问这些 LAN 网段。

预览包含连接密码，只能复制到可信设备。草稿尚未保存并应用时，不要先把预览分发给客户端。

## 运行检查

保存并应用后点击 **运行检查**。MSM 会检查：

1. 当前核心的完整配置是否有效
2. 当前核心服务是否运行
3. 本机 TCP 监听端口是否可连接
4. 是否已经填写公网入口信息

::: danger 本机检查不等于公网可达
MSM 无法从家庭网络外部证明端口转发、防火墙、运营商 CGNAT 或公网路由已经正确。最终必须关闭手机 Wi-Fi，或使用真正位于外网的设备访问家庭 LAN 地址。
:::

## 配置安全与回滚

- 保存前使用当前活动核心校验完整配置
- 核心正在运行时，“保存并应用”会重启当前核心并等待监听器就绪
- 应用失败会恢复原配置，再尝试恢复旧核心运行状态
- 密码会写入当前核心配置，请不要粘贴到日志、工单或公开聊天
- 重新生成密码后，所有已导入旧密码的设备都必须同步更新

## 常见问题

### 本机检查通过，但外网无法连接

- 检查是否真的拥有公网地址，出口 IP 不代表可入站
- 确认路由器同时转发 TCP 和 UDP
- 检查宿主机防火墙、云安全组和上级光猫
- Docker 用户确认发布端口、目标端口和监听端口的对应关系
- 用家庭网络之外的连接测试

### 可以连接，但访问不到家中设备

- 核对客户端规则中的家庭 LAN CIDR
- 确认规则位于兜底规则之前
- 检查家庭设备自身防火墙和回程路由
- 多个 LAN 网段需要逐行加入配置

### 保存时提示 Docker 端口不一致

把监听端口改成页面显示的容器目标端口，或者修改 Compose 映射并重建容器。不要只修改公网发布端口而忽略容器目标端口。

### 切换代理核心后怎么办？

切换到另一个核心后，重新进入 **代理服务 → 回家** 检查配置，执行校验和运行检查，再确认客户端参数没有变化。
