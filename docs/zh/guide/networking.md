# 自建私网

**自建私网**用于把外出设备、异地住宅或服务器加入同一个虚拟网络。MSM 提供 EasyTier、Tailscale 和 WireGuard 三种引擎的安装、配置、服务控制、成员接入和诊断。

::: warning 仅连接已授权成员
私网可以让远端设备获得内网路由。只向可信成员发放凭据，只发布必要的网段，并确保所有目标均属于自有或已授权资产。成员离开或凭据暴露后应立即撤销和轮换。
:::

该模块属于 Pro 功能，并受 **系统设置 → 功能开关 → 穿透与组网** 控制。管理员和操作员可以配置，查看者只能读取状态。

## 三种引擎怎么选

| 引擎 | 适合场景 | 主要特点 |
|------|----------|----------|
| **EasyTier** | 新手、点对点组网、希望减少中心依赖 | 配置直观，可使用公共中继或已有 Peer |
| **Tailscale** | 已使用 Tailscale / Headscale 控制面 | 自动分配地址，可接受路由或发布出口节点 |
| **WireGuard** | 追求简单、高性能和完全可控 | 需要明确配置 Endpoint、地址和 Peer |

一个 MSM 实例当前只管理一套活动私网配置。更换引擎前记录现有地址、路由和成员资料，不要把三种引擎的配置混用。

## 创建私网

进入 **穿透与组网 → 自建私网**，点击创建或设置：

1. **选择引擎**：EasyTier、Tailscale 或 WireGuard
2. **设置身份**：网络名称、本机节点名称、虚拟网段和本机虚拟地址
3. **设置连接**：按引擎填写 Endpoint、控制面或初始 Peer
4. **确认创建**：保存配置、安装对应二进制并启动服务

建议启用自动启动。保存完成不代表运行就绪，仍需确认二进制已安装、服务状态为运行中，并执行诊断。

## EasyTier

EasyTier 适合快速建立点对点网络：

- 可启用公共中继节点
- 也可填写一个或多个已有 Peer 作为初始连接
- 可发布家庭 LAN 路由，让远端访问局域网
- 成员接入时会生成网络参数和共享密钥材料

共享密钥可以让设备加入整个 EasyTier 网络，应通过可信渠道传递并妥善保存。

## Tailscale / Headscale

Tailscale 模式需要：

- HTTPS 控制服务器地址
- 对应控制面的 Auth Key
- 可选接受其他节点发布的路由
- 可选把当前节点发布为出口节点
- 可选发布家庭 LAN 路由

使用 Headscale 时填写自己的 Headscale HTTPS 地址。控制服务器变更后，原 Auth Key 不再视为可复用，需要填写新控制面签发的 Key。

保存的 Auth Key 不会在页面中回显。确认节点注册完成后，可按控制面策略撤销一次性 Key。

## WireGuard

WireGuard 需要一个远端可达的 Endpoint。向导支持：

- 自动检测公网地址
- 选择 [域名服务](/zh/guide/domain-services) 中已验证的 DDNS 任务
- 手动填写域名或地址

同时设置监听端口、虚拟网段、本机地址和需要发布的家庭 LAN CIDR。使用公网 Endpoint 时，还需在路由器与防火墙中放行并转发对应 UDP 端口。

::: warning DDNS 必须先就绪
向导会显示 DDNS 任务是否已经完成验证。不要选择仍处于等待传播或同步失败状态的域名作为生产 Endpoint。
:::

## 添加成员

在成员区域点击添加设备，填写设备名称和需要的远端路由。根据引擎不同，MSM 会生成接入资料或引导到对应控制面。

WireGuard 客户端私钥只在创建接入包时返回一次，不会由 MSM 持久化。关闭对话框前立即复制到目标设备，并删除不再需要的临时副本。

发布远端 LAN 路由前确认两端网段不冲突。例如两地都使用 `192.168.1.0/24` 时，无法仅凭路由判断目标站点，应先调整其中一侧网段。

## 路由与出口节点

- **发布家庭 LAN 路由**：让远端访问当前站点的局域网
- **接受路由**：允许本机使用其他节点发布的网段
- **发布出口节点**：允许其他设备把互联网流量经本机转发
- **远端路由**：记录成员背后的局域网网段

只发布真正需要的 CIDR。出口节点会扩大带宽、隐私和合规责任，启用前确认上行能力与访问边界。

## 诊断

创建并启动后点击 **诊断**，依次核对：

- 二进制和配置是否存在
- 服务进程是否运行
- 虚拟接口与地址是否建立
- Endpoint / 控制面是否可达
- Peer 或成员是否在线
- 发布路由是否生效

“服务运行”只证明本机进程存在，不代表远端已经接受路由。最终应从外出设备访问 MSM 虚拟地址和一个家庭 LAN 设备。

## 常见问题

### 远端能访问 MSM，不能访问家庭 LAN

- 检查是否填写并发布家庭 LAN CIDR
- Tailscale / Headscale 用户确认控制面已批准路由
- 检查主机 IP 转发、防火墙和家庭设备回程路由
- 确认两端网段没有重叠

### WireGuard 无法握手

- 验证 Endpoint 当前解析结果
- 确认 UDP 端口转发与监听端口一致
- 检查客户端时间、密钥和 AllowedIPs
- 从真正的外部网络测试，避免 NAT 回环干扰

### Tailscale 保存后无法注册

- 控制服务器必须是有效 HTTPS 地址
- Auth Key 必须属于当前控制服务器
- Headscale 用户检查预授权与用户 / 命名空间设置
- 控制服务器变更后重新生成 Key
