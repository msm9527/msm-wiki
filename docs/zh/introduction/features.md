# 核心功能

MSM 的能力分为基础网络链路、统一代理管理、远程接入、家庭服务运维和平台治理。部分高级模块需要 Pro，并受系统功能开关与用户角色限制。

## DNS 与客户端分流

### MosDNS 管理

- 服务安装、版本、启停和状态监控
- 规则、数据源、上游 DNS 和缓存
- 查询日志、统计、排行与审计
- 配置文件编辑、校验和升级迁移

### 双栈 FakeIP

- IPv4 与 IPv6 FakeIP 可同时工作
- DNS、代理核心和主路由网段一致性检查
- DHCP 覆盖本机 DNS 后的网络自愈
- 客户端名单、禁用模式与设备级访问控制

## 统一代理服务

### 多方案

- Clash Meta：Meta 稳定版或 Alpha 预览版
- Clash Smart：专用核心、模板和策略组（Pro）
- reF1nd Sing-Box

三个方案使用统一的概览、节点、规则、连接、配置、日志和远程回家菜单。

MSM 只提供上述核心和用户自有或依法取得使用权配置的管理能力，不提供节点、订阅、网络接入、内容分发或其他违法违规服务。标准版和 Pro 都不包含第三方网络资源；Pro 只扩展管理模块、操作能力和配额。

### 安全切换

- 目标核心下载与家族校验
- 订阅和可兼容配置迁移
- 单一活动核心与进程协调
- 透明代理、DNS 和系统网络规则重建
- 控制器、策略组、订阅和配置接口就绪验证
- 阶段化进度、失败提示和恢复路径

### 节点与配置

- 订阅、Provider、节点、策略组和延迟测试
- 规则、规则集与策略管理
- 实时连接、流量和规则命中
- YAML / JSON 结构化与原始编辑
- 尽量保留原生字段、注释和顺序
- 配置历史、对比与回滚（按能力开放）

## 回家与远程接入

### 多协议远程回家

- Clash 与 Sing-Box 双核心支持
- 支持 Shadowsocks、VLESS、Trojan、AnyTLS、Hysteria2 和 TUIC v5
- 自动检测出口地址与家庭网段建议
- 服务端配置与客户端 YAML 预览
- 按协议提示 TCP / UDP 转发，并检查 Docker 发布端口 / 目标端口
- 完整配置校验、监听检查和失败回滚

### Cloudflare 双通道

- 网页穿透：使用 HTTPS 域名访问 Web 服务
- 云端私网：访问 SSH、远程桌面、数据库和 LAN
- 两个通道独立配置并可同时运行
- 安装、注册、路由、配对与状态检查

### 自建私网

- EasyTier：点对点与中继组网
- Tailscale / Headscale：控制面注册、路由和出口节点
- WireGuard：Endpoint、Peer 和一次性客户端密钥
- 服务安装、自动启动、成员管理与诊断

## 域名服务

### DDNS

- 加密保存服务商凭据
- IPv4 / IPv6 来源与定时更新
- 服务商写入和权威解析双重状态
- 重试、错误记录与手动诊断

### HTTPS 证书

- Let's Encrypt、ZeroSSL 和受限的自定义 ACME
- DNS-01 简单模式
- HTTP-01 / TLS-ALPN-01 专家模式与预检
- PEM 导入、证书链和私钥匹配校验
- 自动续期、退避重试和运行时加载

### 反向代理

- 域名到内网 HTTP / HTTPS 服务
- WebSocket、路径、Header、超时、重试和多上游
- 健康检查、访问日志和发布链路诊断
- 配置安全加载与失败恢复
- DDNS → 证书 → 代理的一键可恢复工作流

## Docker 管理

### 多目标

- 本机 Docker Engine
- 最多三个轻量 Agent 子节点
- Agent HTTPS 直连或主动回连
- 一次性接入令牌、凭据轮换和健康监控

### 资源工作台

- 容器生命周期、批量操作、日志、终端、文件和统计
- 镜像搜索、拉取、导入、导出、层与清理
- 存储卷、网络、地址池和资源关系
- Compose / Stack 验证、模板和生命周期
- 事件、更新检查、系统信息和磁盘回收

## 网络工具

- Ping、MTR、Traceroute
- DNS、HTTP、SSL、WHOIS / RDAP、IP 信息
- 互联网测速、本机基线、iPerf3
- 端口扫描、ARP、接口、子网计算和 WOL
- IPv6、NAT 与路由视角检查
- 实时流、取消、历史和诊断组合

## 平台与安全

### 账号与授权

- 管理员、操作员、查看者角色
- 会话和 API Token
- Pro 能力按功能细分
- 高风险操作的后端二次授权

### 配置与数据

- 原子写入、配置校验和失败回滚
- 敏感日志脱敏
- 凭据、私钥和控制面密钥隔离
- 备份、恢复、历史和升级迁移

### 部署与运行

- Linux、macOS、Alpine、Docker
- 单二进制内嵌前端
- 系统服务与后台恢复
- 中英文界面和响应式布局
