# Cloudflare 穿透与组网

MSM 将 Cloudflare 能力分成两个互不依赖的通道：

| 通道 | 用途 | 远端设备是否需要客户端 |
|------|------|------------------------|
| **网页穿透（Tunnel）** | 用 HTTPS 域名访问 MSM 或家庭 Web 服务 | 不需要，浏览器即可访问 |
| **云端私网（Mesh）** | 访问 SSH、远程桌面、数据库和家庭 LAN 网段 | 需要加入对应私网 |

两个通道可以同时运行。切换页面卡片只会改变下方正在编辑的设置，不会停止另一个通道。

该模块属于 Pro 功能，并受 **系统设置 → 功能开关 → 穿透与组网** 控制。

## 选择哪一种

- 只想从外网打开一个网页：选择 **网页穿透**
- 想像在家一样访问多个 IP、端口或非 HTTP 服务：选择 **云端私网**
- 希望完全自建控制面或使用 EasyTier / Tailscale / WireGuard：选择 [自建私网](/zh/guide/networking)
- 已有公网 IP 和端口转发，且使用代理客户端：也可选择 [Shadowsocks 回家](/zh/guide/home)

## 网页穿透（Tunnel）

进入 **穿透与组网 → 网页穿透**。

### 快速配置方式

MSM 支持两类配置路径：

1. **使用现有 Tunnel Token**
   - 在 Cloudflare 控制台创建 Tunnel
   - 复制 Tunnel Token
   - 填写本地服务地址和公开域名
2. **API 自动配置**
   - 填写 Account ID、Zone ID 和最小权限 API Token
   - 填写 Tunnel 名称、公开域名和本地服务地址
   - 由 MSM 创建或配置所需资源

页面可以自动安装连接器、保存配置、启动服务，并逐项显示安装、连接、地址和保护状态。完成后应看到公开 HTTPS 地址和在线状态。

### 本地服务地址

填写的是 Cloudflare 连接器实际能够访问的地址：

- 宿主机安装通常可使用本机监听地址
- Docker 中的 `127.0.0.1` 指向容器自身，不一定是宿主机服务
- 发布其他容器时优先使用同一 Docker 网络中的服务名，或明确可达的宿主机地址

### 访问保护

Tunnel 解决的是传输与入口，不会自动替代应用认证。公开管理界面前建议配置 Cloudflare Access，并保留 MSM 自身的强密码和权限控制。

## 云端私网（Mesh）

进入 **穿透与组网 → 云端私网**。页面提供新手配置和高级配置，可填写站点、设备、组织信息以及要发布的家庭网段。

典型流程：

1. 获取 Cloudflare 账户与私网所需凭据
2. 填写站点名、设备名和家庭 LAN CIDR
3. 安装并注册连接器
4. 启动服务，等待连接和路由检查通过
5. 将外出设备加入同一私网
6. 从外网访问家庭 LAN 地址并验证路由

家庭网段应填写真实 CIDR，例如 `192.168.1.0/24`，不要填单个设备地址，也不要与远端网络使用的网段冲突。

## 站点配对

云端私网支持导出和导入配对文件，用于交换两个站点的路由信息：

1. 在源站点导出配对文件
2. 通过可信渠道发送给目标站点
3. 在目标站点导入并核对源、目标站点和 CIDR
4. 完成配对后分别验证双向路由

配对材料可能包含一次性敏感信息，只应通过可信渠道传递；完成后不要长期保留在共享目录。

## 兼容性检查

Cloudflare 产品、账户套餐和 API 能力可能变化。配置前先运行页面提供的兼容性与权限检查，并以当前 Cloudflare 控制台显示的能力为准。

如果检查失败：

- 确认 Token 属于正确账户和区域
- 检查 Token 权限是否覆盖所需资源
- 确认组织 / Team 名称与当前账户一致
- 检查家庭 LAN CIDR 是否冲突
- 查看连接器状态和路由检查详情

## 服务控制

两个通道都有独立的保存、安装、启动、暂停 / 停止和刷新操作。修改配置后应：

1. 保存当前通道
2. 安装或确认连接器存在
3. 启动当前通道
4. 等待状态变为在线
5. 从真正的外部网络验证

停止网页穿透不会自动停止云端私网，反之亦然。

## 安全建议

- API Token 使用最小权限，不使用全局 API Key
- 不在日志、截图、工单中暴露 Token、Account ID 组合或配对材料
- 网页穿透配合 Cloudflare Access 和应用自身认证
- 私网只发布需要的家庭 CIDR，避免无边界发布全部路由
- 定期撤销不再使用的设备、Token 和路由

## 常见问题

### 显示在线但域名打不开

检查公开域名 DNS、Tunnel 路由、本地服务地址和容器网络。在线只说明连接器与 Cloudflare 建立了连接，不代表本地服务一定可达。

### 私网连接成功但访问不到 LAN

检查发布的家庭 CIDR、远端接受路由状态、网段冲突、主机转发和家庭设备回程路径。

### 两个通道能共用同一个连接器配置吗？

界面把它们作为独立通道管理。不要因为一个通道已在线就假设另一个也已配置；分别完成各自的保存、启动与检查。
