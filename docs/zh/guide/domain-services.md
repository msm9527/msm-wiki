# 域名服务（Edge 网关）

**域名服务（Edge 网关）**将动态域名解析（DDNS）、HTTPS 证书管理、L7 反向代理、L4 端口转发、STUN 内网穿透与服务拓扑整合在同一工作台，适合把 NAS、相册、家庭面板及 TCP/UDP 服务安全、可观测地对外发布。

::: warning 域名和服务授权
仅可修改自有或已授权域名的 DNS，为已授权域名申请证书，并转发或代理自有及已授权服务。公网发布前应开启身份验证、HTTPS、最小暴露面和必要的访问审计。
:::

该模块属于 Pro 扩展能力，首次使用需在 **应用商店（`/apps`）** 安装并在 **系统设置 → 功能开关 → 域名服务** 中开启。

MSM 已采用**进程内纯 Go Edge 网关引擎**，直接由 MSM 自身承载 HTTP/HTTPS 反向代理、ACME 证书加载、L4 TCP/UDP 转发与配置热更新，**无需额外安装或维护 Caddy 等外部反向代理二进制**。

当前工作区包含：

| 工作区 | 路由 | 核心能力 |
|--------|------|----------|
| **概览** | `/edge/overview` | 汇总 DDNS、证书、L7/L4 规则与网关引擎健康状态，提供一键发布向导 |
| **服务拓扑** | `/edge/topology` | 可视化展示公网入口、域名/证书、路由规则、L4 转发、STUN 隧道与内网上游之间的关联状态 |
| **动态域名解析** | `/edge/ddns` | 管理 DNS 服务商凭据、IPv4/IPv6 双栈 DDNS 任务、权威解析核验与诊断 |
| **证书管理** | `/edge/certificates` | ACME（DNS-01 / HTTP-01 / TLS-ALPN-01）自动签发、续期与已有 PEM 证书导入 |
| **反向代理** | `/edge/proxy` | L7 HTTP/HTTPS 反向代理、重定向、静态响应、多上游负载均衡、上游发现探测与导入导出 |
| **端口转发** | `/edge/forwards` | L4 TCP / UDP 端口转发与连通性管理 |
| **穿透隧道** | `/edge/tunnels` | STUN NAT 穿透隧道管理，辅助无标准公网端口环境暴露服务 |

## 发布链路

```text
内网服务（HTTP / HTTPS / TCP / UDP）
  ↓ 上游发现与健康检查
DDNS：域名指向家庭公网 IPv4 / IPv6
  ↓ 权威解析验证
ACME：自动签发或导入 HTTPS 证书
  ↓ 进程内 Edge 引擎热加载
反向代理（L7）/ 端口转发（L4）/ STUN 隧道
  ↓
公网可达性检查、服务拓扑与访问日志
```

## 快速发布一个域名

进入 **域名服务 → 概览**，点击 **发布一个域名**。向导会分阶段完成校验与落地：

1. 填写服务名称、域名和内网目标 URL（支持直接从局域网或 Docker 容器发现上游服务）
2. 新建或选择 DNS 服务商凭据
3. 创建并同步 DDNS 记录，等待权威解析核验
4. 申请新证书或复用已有通配符证书
5. 创建反向代理路由并通过配置校验与热加载
6. 对公网域名执行最终 HTTPS 可达性检查

每个阶段均包含预检，失败后可直接修正当前阶段继续，无需重复创建已成功资源。

## 动态域名解析（DDNS）

进入 **域名服务 → 动态域名解析** 管理 DNS 凭据和同步任务。

### 建议流程

1. 使用服务商提供的最小权限 API Token / 密钥
2. 测试凭据连通性
3. 填写域名、记录类型（A / AAAA / 双栈）、TTL 与检测周期
4. 按地址族分别选择公网 IPv4 / IPv6 获取来源（接口读取、直连探测服务或自定义脚本；直连探测会自动绕过代理与环境 `HTTP_PROXY`）
5. 保存并点击 **立即同步**，确认服务商写入状态与权威 DNS 解析一致

DNS 凭据字段在保存后默认掩码展示，留空保存保留原值；管理员可通过查看图标临时核对。出现「已写入但尚未传播」时，请等待 TTL 生效，不必反复删除重建。

::: tip 与自建私网联动
WireGuard 自建私网可直接引用已就绪的 DDNS 任务作为 Endpoint。建议先让 DDNS 通过权威解析验证，再进入 [自建私网](/zh/guide/networking)。
:::

## HTTPS 证书管理

进入 **域名服务 → 证书管理**。

### ACME 自动签发

- **DNS-01（默认推荐）**：支持通配符证书（如 `*.example.com`），不要求公网开放 `80` / `443` 端口；支持 Let's Encrypt、ZeroSSL 及自定义 ACME Directory
- **HTTP-01 / TLS-ALPN-01（高级模式）**：分别依赖公网 `80` / `443` 端口直达当前 Edge 引擎，不支持通配符
- 首次接入建议先用 **Staging** 环境验证流程，通过后再切换 **Production** 签发正式证书（避免触发 CA 速率限制）

### 导入已有证书

支持直接粘贴 PEM 或从 MSM 配置目录下受限的 `imports` 路径导入，保存前自动校验完整证书链、域名匹配、有效期及私钥一致性。私钥在数据库内加密存储，请勿在截图、日志或工单中泄露。

### 自动续期与保护

- 证书进入续期窗口后自动触发续期，失败按退避策略重试并展示下次重试时间
- 续期失败时保留尚未过期的旧证书继续服务，不中断业务
- 已被路由引用的证书受删除保护，需先解绑或切换证书

## 反向代理（L7）

进入 **域名服务 → 反向代理**。内置 Edge 网关引擎负责配置校验、热重载与失败回滚；默认不主动占用 `80` / `443`，只有在创建并启用使用对应监听端口的路由后才启动监听。

创建路由时可选择三种类型：

| 类型 | 适用场景 | 关键设置 |
|------|----------|----------|
| **反向代理** | 将域名或路径转发至一个或多个内网服务 | 上游发现与探测、多上游负载均衡（随机/轮询/最少连接）、主动健康检查、超时重试、上游 TLS SNI / 自定义 CA、Header 改写 |
| **重定向** | 将访问跳转至另一个 URL | 目标 URL 与 301/302/307/308 状态码 |
| **静态响应** | 直接返回固定状态与文本/JSON | HTTP 状态码、响应体与响应头 |

补充能力：

- 支持按域名 + 路径前缀匹配、优先级排序与路径前缀剥离
- 支持从局域网或本机 Docker 快速发现并探测上游服务
- 支持批量启用/停用/删除、复制路由及配置导入导出
- 保存与重载前强制校验域名、监听端口、证书与上游合法性，加载失败自动保留上一份可用配置

### 上游目标地址建议

- **MSM 与目标同机**：填写目标服务实际监听地址和端口
- **MSM 运行在 Docker Bridge 模式**：不要用 `127.0.0.1` 指代宿主机服务，请使用宿主机 LAN IP 或同网络容器名
- **上游使用自签名 HTTPS**：优先配置上游 CA 与 SNI，避免直接关闭 TLS 校验

## 端口转发（L4）与穿透隧道

### L4 端口转发（`/edge/forwards`）

面向非 HTTP 协议（如 SSH、数据库、游戏服务器、自建协议或远程桌面）提供 TCP / UDP 四层转发，直接由内置 Edge 引擎承载，支持独立启停、监听地址绑定与目标可达性验证。

### STUN 穿透隧道（`/edge/tunnels`）

面向无公网 IPv4 但处于全锥形 NAT（NAT1）环境的用户，提供 STUN 打洞探测与端口映射辅助，并可在服务拓扑中查看映射状态。

## 服务拓扑、状态与诊断

- **服务拓扑（`/edge/topology`）**：一张图看清公网域名/端口 → 证书 → 路由/转发规则 → 内网上游的健康状态，快速定位哪一段出现故障
- **分阶段诊断**：
  1. **DDNS 诊断**：核对公网 IP 探测来源、DNS 写入记录与权威解析结果
  2. **证书状态**：检查签发环境、挑战方式、到期时间与运行态加载
  3. **上游健康检查**：测试内网目标连通性、HTTP 状态码与延迟
  4. **引擎状态与访问日志**：核对端口冲突、监听绑定、按关键词与状态码筛选访问日志及 P95 延迟

## 安全建议

- DNS 凭据仅授予对应域名的最小操作权限
- 公网发布家庭管理面板时，务必叠加登录认证、HTTPS、访问控制或优先改用 [自建私网](/zh/guide/networking) / [远程回家](/zh/guide/home)
- Docker 部署别忘记映射路由或转发实际使用的监听端口
- 删除证书或上游前先检查拓扑中的引用关系
