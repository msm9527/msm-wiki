# 使用与合规中心

> 版本：`1.1` · 更新日期：2026 年 8 月 19 日

::: info 产品定位
MSM 是闭源的自托管网络与系统管理软件，用于管理用户自有或已获授权的设备。它将 DNS、代理核心、域名服务、远程接入、Docker 运维和网络诊断统一到管理界面，不是网络接入服务、代理节点、订阅或内容提供服务。标准版与 Pro 的差异是软件管理能力和配额，不包含任何网络线路。
:::

## 使用原则

1. 只管理自己拥有或已获授权的设备、网络、域名、账号和数据。
2. 用户自行负责配置来源、第三方服务、账号安全、备份和当地合规。
3. MSM 自有代码采用闭源许可；第三方程序和数据仍按各自许可证使用。

## 合法合规的典型用法

- 管理自己的家庭网络、实验环境、服务器或 Docker 资源
- 在组织明确授权的范围内进行 DNS、路由、端口和连通性诊断
- 为自有域名、证书和 Web 服务配置 DDNS 与反向代理
- 为自有设备建立经过身份验证和加密的远程访问
- 将自己合法获取的配置、规则和订阅接入兼容组件

## 合规提醒

不同地区、组织和使用场景的要求可能不同。用户应根据自己的部署和数据范围确认适用要求；生产环境或高风险场景应在上线前完成必要的安全与合规评估。
